# akshaj.shah

An interactive conversational interface for exploring my background, projects, and experience. Built as an alternative to a static resume — ask questions, get answers grounded in real work.

## Stack

- Vanilla HTML/CSS/JS frontend (no build step)
- Serverless API on Vercel
- Anthropic Claude API for conversational responses

## Local Development

```bash
npm install -g vercel
vercel dev
```

Requires an `ANTHROPIC_API_KEY` environment variable.

## Deployment

Deployed on Vercel. Environment variables configured via the Vercel dashboard.
